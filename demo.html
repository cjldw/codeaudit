📝 About This Demo

This demonstration shows how to use WebAssembly (WASM) to override JavaScript's console.log function. The WASM module intercepts console calls and adds custom formatting, timestamps, and processing before displaying the output.

Note: Open your browser's Developer Tools (F12) to see the console output with WASM processing!

📊 How It Works

  1. WASM Module: Compiled from C code using Emscripten
  2. JavaScript Wrapper: Loads WASM and overrides console functions
  3. Memory Management: Handles string passing between JS and WASM
  4. Custom Processing: Adds timestamps and formatting in WASM
